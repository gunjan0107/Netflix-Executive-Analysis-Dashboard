# Netflix Executive Analytics Dashboard

## Project Overview
This project is intended to present a high-level view of the Netflix titles dataset for a non-technical audience. The dashboard should bring together a small set of summary metrics and visualizations to help readers explore the catalogue.

## Objective
- Consolidate key catalogue metrics.
- Compare Movies and TV Shows.
- Summarize release-year patterns and geographic distribution.
- Present findings in a clean, executive-friendly Excel dashboard.

## Dataset
The supplied dataset contains **8,790 records** and includes:
`show_id`, `type`, `title`, `director`, `country`, `date_added`, `release_year`, `rating`, `duration`, and `listed_in`.
